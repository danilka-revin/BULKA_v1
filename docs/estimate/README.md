# Данные сметы

Из таблиц этого каталога собирается [`../COST_ESTIMATE.md`](../COST_ESTIMATE.md) —
смета на изготовление робота с фотографиями, ценами и ссылками на предложения.

## Файлы

| Файл | Что в нём | Кто правит |
| :--- | :--- | :--- |
| [`parts.csv`](parts.csv) | состав робота: позиция, количество, ключ цены, статус, основание | человек |
| [`price_observations.csv`](price_observations.csv) | найденные предложения: ключ, цена в рублях, продавец, ссылка | человек |
| [`estimate.json`](estimate.json) | дата цен, курс доллара, разделы, прочие затраты, прежняя калькуляция | человек |
| [`photo_sources.json`](photo_sources.json) | откуда взята каждая фотография | `tools/estimate/add_photo.py` |
| [`cost_estimate_calculated.csv`](cost_estimate_calculated.csv) | те же позиции с рассчитанными ценами и суммами | генератор |

## Как считается цена

Строка `parts.csv` ссылается на предложения через `price_key`. Цена позиции —
медиана предложений этого ключа с отметкой `да` в колонке `use`; при двух
предложениях это их среднее. Предложение с отметкой `нет` остаётся в таблице
и в приложении А сметы, но в расчёт не входит; причина пишется в `note`.

У строки без `price_key` цена берётся из `manual_price_rub`, а статус должен
быть `оценка`.

## Статус позиции

| Статус | Когда ставится |
| :--- | :--- |
| `по документам` | изделие названо в документах проекта, в прошивке или в документации бортового ПО |
| `допущение` | модель или количество в документах не названы и подобраны по смыслу; пояснение обязательно |
| `оценка` | цена назначена без поиска предложений; пояснение обязательно |

## Как обновить смету

```bash
# 1. Исправить parts.csv, price_observations.csv или курс в estimate.json
# 2. Пересобрать
python3 tools/estimate/build_estimate.py
# 3. Проверить
python3 -m venv .venv-test && .venv-test/bin/pip install pytest
.venv-test/bin/python -m pytest tools/estimate -q
# 4. Пересобрать PDF документов
.venv/bin/python tools/pdf/md2pdf.py
```

Итоги сметы процитированы в `README.md`, `docs/TECHNICAL_SPECIFICATION.md`,
`docs/EXPLANATORY_NOTE_AVTOVAZ.md` и `docs/ZAPRET_SYNC.md`. После пересчёта их
нужно поправить руками: тест `test_documents_quote_the_current_totals` не
пройдёт, пока суммы там не совпадут с расчётом. Текущие итоги одной командой:

```bash
python3 tools/estimate/build_estimate.py --totals
python3 tools/estimate/build_estimate.py --rate 90   # то же при другом курсе доллара
```

## Как добавить позицию

1. Добавить строку в `parts.csv`: номер вида `раздел.номер`, раздел из
   `estimate.json`, количество, единицу, статус и основание.
2. Добавить в `price_observations.csv` найденные предложения с тем же ключом.
   Годится только предложение, где однозначно видны товар и цена в рублях.
3. Добавить фотографию (нужен Pillow):

   ```bash
   .venv/bin/python tools/estimate/add_photo.py gy87.jpg ~/Downloads/gy87.png \
       --url https://example.org/gy87 --title "Модуль GY-87"
   ```

   Скрипт уменьшает снимок до 180 × 180 точек и записывает источник.
4. Пересобрать смету и запустить тесты.
